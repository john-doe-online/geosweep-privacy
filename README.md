# GeoSweep Privacy Policy

Static privacy-policy page for GeoSweep, intended to be hosted with GitHub Pages.

## Before publishing

Edit `index.html` and replace **all** occurrences of:

- `PUBLISHER_NAME` with the public/legal publisher name you want to identify in the policy.
- `PRIVACY_EMAIL` with a working privacy/support email address.

Do not publish the page with those placeholders still present.

## Enable GitHub Pages

In the GitHub repository:

1. Open **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/ (root)**.
5. Save.

For the repository `john-doe-online/geosweep-privacy`, the expected public URL is:

`https://john-doe-online.github.io/geosweep-privacy/`

Once GitHub Pages reports the site as published, open that URL in a private/incognito browser
to verify it is publicly accessible, then use that HTTPS URL in AdMob and Google Play.

## Current scope

This policy currently describes:

- GeoSweep local gameplay/preferences storage.
- Google AdMob / Google Mobile Ads.
- Google User Messaging Platform (UMP).
- No Firebase Analytics or Firebase Crashlytics integration.

If analytics, crash reporting, login/accounts, cloud saves, purchases, or other SDKs are added later,
update the policy before release.
